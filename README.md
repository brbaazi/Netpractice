# NetPractice 🌐

**NetPractice** is a 42 School project focused on understanding the basics of **computer networking**.

The project helps learn how devices communicate using **IP addresses, subnet masks, and routing**.

## 🧠 Concepts

* IP Addresses
* Subnet Masks
* CIDR Notation
* Network Addresses
* Host Addresses
* Default Gateways
* Routers
* TCP/IP basics
* Routing

## 🎯 Goal

The goal is to configure small network diagrams correctly by assigning valid IP addresses and subnet masks.

## 🛠️ What I Learned

* How IP addresses work
* How subnet masks divide networks
* How to calculate network and host addresses
* How routers connect different networks
* How to identify valid IP ranges
* How to configure simple network topologies

## 📚 42 School

NetPractice is part of the **42 School Common Core** and introduces the fundamental concepts needed to understand computer networks.
